# ТОЧКА — демо автосервиса

Создано 19 октября 2026 года для портфолио Jolylolly. Полностью вымышленный бизнес: название используется как концепт, адрес, телефон, услуги, цены, сроки и кейсы демонстрационные. Никаких реальных отзывов или достижений не заявлено.

## Запуск

Откройте `START-DEMO.cmd` двойным щелчком. Либо в этой папке выполните `npm ci` (первый запуск), затем `npm start`.

- Сайт: http://localhost:4321
- CMS: http://localhost:4321/admin/
- Остановка: Ctrl+C в окне запуска.
- Требуется Node.js 22.22+; проект проверен на Node.js 24.

## Редактирование

1. Запустите проект командой `npm start` и откройте CMS.
2. Нажмите «Войти». В локальном режиме пароль не нужен; сервер доступен только на этом компьютере.
3. Откройте «Сайт автосервиса» → «Тексты, услуги и работы».
4. Измените поля. В списках можно добавлять, переставлять и удалять элементы. Картинки можно загружать через редактор.
5. Нажмите «Опубликовать» → «Опубликовать сейчас».
6. Обновите вкладку сайта. Изменения сохраняются в `src/content/site.json`, изображения — в `public/images`. В режиме разработки Astro использует их сразу.

Редактируются название, первый экран, главное фото, телефон, адрес, часы, услуги с ценами и подробностями, кейсы с фотографиями, вопросы и ответы. Это реальная файловая headless CMS Decap, а не имитация на localStorage.

Слово «Опубликовать» — название кнопки Decap. Здесь оно означает сохранение локальных файлов, а не размещение в интернете. Для статической версии после правок нужен `npm run build` и повторная публикация сборки.

## Стек и структура

- Astro 7, Tailwind CSS 4, статическая сборка.
- Decap CMS 3.17.1; скрипты редактора хранятся локально, исходный npm-архив сохранён в `assets`.
- `src/pages/index.astro` — страница и сценарии взаимодействия.
- `src/styles/global.css` — адаптивные стили с Tailwind и CSS.
- `src/content/site.json` — структурированные данные для CMS.
- `public/admin/config.yml` — схема редактора.
- `public/images/*.webp` — сжатые изображения сайта.
- `assets/originals` — исходные сгенерированные PNG.
- `screenshots` — первый экран, работы, форма, мобильная версия и CMS.
- `dist` — проверенная статическая сборка; не опубликована.

## Что работает

- Адаптивная страница, мобильное меню, переходы по разделам.
- Раскрывающиеся услуги, выбор услуги в форме.
- Фильтрация работ и подробные кейсы в модальных окнах, закрытие Escape.
- FAQ, плавные появления и hover-эффекты с поддержкой reduced motion.
- Валидация полей формы, демонстрационный результат, сброс введённых значений.
- Сохранение CMS на диск и отображение изменений на сайте.

## Статус интеграций

**Форма не принимает реальные заявки.** Она не делает сетевых запросов, не сохраняет данные и не создаёт запись. После демонстрации очищает поля. Номер +7 (000) 000-00-00 намеренно не является телефонной ссылкой. Карта схематическая и не ведёт к реальному адресу.

**CMS работает локально.** Для владельца, который будет редактировать сайт через интернет, потребуется выбрать Git-репозиторий, настроить поддерживаемый Decap backend и авторизацию, доступы владельца, а также пересборку и доставку сайта после изменений. Локальный proxy-сервер нельзя выставлять в интернет. Само размещение статической сборки на Sites не подключает удалённую CMS автоматически.

**Публикация:** не выполнялась по правилу AGENTS.md, требующему отдельного поручения. Использован локальный процесс навыка Sites. При поручении публикации `dist` можно подготовить для Sites; идентификатор сайта пока не создан.

Для боевого запуска также нужны реальные материалы и реквизиты, согласованный канал заявок, проверка доставки заявки и согласованные тексты обработки данных.
